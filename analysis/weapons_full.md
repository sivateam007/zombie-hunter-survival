# Weapon getter bodies (verbatim)

Generated by `analysis/full_teardown.js` from `zh_orig_assets/weapons_prototypes.json`.

These are the bundle's own prototype functions, so damage/count/radius scaling is exact.


## Axe

- name: `WEAPON_NAME_AXE`
- evolution: `WEAPON_NAME_BATTLEAXE` via `Supplements`


**reset**

```js
{this.level=1;
this.speed=.25;
this.cooldown=2500;
this.delay=.1*this.getCooldown();
this.evoAired=!1}
```


**getCount**

```js
{return 1}
```


**getDamage**

```js
{var b=5*Player.instance.getAttrib("attack");
2==this.level&&(b*=1.25);
3==this.level&&(b*=1.5);
4==this.level&&(b*=1.75);
5==this.level&&(b*=2);
5<this.level&&(b*=4);
return b}
```


**getRadius**

```js
{var b=80;
2==this.level&&(b*=1.1);
3==this.level&&(b*=1.2);
4==this.level&&(b*=1.4);

5==this.level&&(b*=1.5);
5<this.level&&(b*=2.5);
return b+Math.floor(Player.instance.attribs.shot_range_bonus*b)}
```


**getCooldown**

```js
{return Math.ceil(this.cooldown-this.cooldown*Player.instance.attribs.cooldown_bonus)}
```
